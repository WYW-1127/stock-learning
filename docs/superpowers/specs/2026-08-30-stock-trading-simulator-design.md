# A股模拟炒股学习网页 — 设计文档

日期:2026-08-30
状态:已经用户确认(brainstorming 会话)

## 1. 概述

给股票零基础用户的学习型 A 股模拟炒股网页。用**真实行情数据**(腾讯/东方财富免费接口),按**完整 A 股交易规则**(T+1、涨跌停、佣金/印花税/过户费、按手申报)模拟买卖,零本金风险。配套术语知识卡、交易复盘、新手引导教程辅助学习。

- 单人本地使用,Windows 环境,双击 `启动.bat` 即用
- 初始虚拟资金 10 万元,可一键重置账户
- 随时可交易:盘中按实时价成交,盘后/周末按最新收盘价成交(界面明确标注"盘后模式")
- 第一期只做股票;基金、挂单等见"非目标"

### 成功标准

1. 用户能完成完整学习循环:搜股票 → 加自选 → 看K线 → 买卖(含费用明细)→ 看持仓盈亏 → 复盘统计 → 查术语/教程
2. 费用与规则计算正确(单元测试覆盖),盘后可用,数据跨会话保留
3. 每个界面指标可点出通俗解释;首次打开有新手引导

## 2. 范围与非目标

### 非目标(第一期不做)

- 场外基金申赎(第二期候选)
- 挂单/撤单等待成交、集合竞价模拟(撮合只做即时成交)
- 北交所股票交易(可搜索到但不提供交易,提示不支持)
- 新股上市初期(N/C 开头)交易——规则特殊,不模拟错误的比硬模拟好;可加自选观察
- 融资融券、期权、港美股
- 多账户、在线部署、手机端深度适配(桌面浏览器优先,基础响应式即可)

## 3. 功能设计(五个页面)

### 3.1 行情页(首页)

- 顶部:上证指数、深证成指、创业板指三大指数实时涨跌卡片
- 自选股列表:实时价格、涨跌幅、涨跌额,随前端 5 秒轮询刷新;按钮移除自选
- 搜索框:输入代码或名称片段(如"600519"或"茅台"),下拉候选,回车进个股页;可一键加自选

### 3.2 个股详情页

- K 线图(klinecharts 库):分时 / 日K / 周K 切换,日K 默认 120 根,前复权
- 报价区:现价、涨跌幅、今开/昨收/最高/最低、成交量、成交额、换手率、市盈率、市净率、振幅、流通市值/总市值
- 五档盘口:买一到买五、卖一到卖五的价格和量
- 醒目"买入""卖出"按钮(无持仓时卖出按钮置灰)
- **术语卡**:所有指标标签可点击,弹出行内通俗解释

### 3.3 交易(下单面板)

- 从个股页弹出:股票信息头、价格输入(默认现价,可改)、数量输入(按股,提示"1手=100股")、快捷手数按钮(1手/半仓/全仓)
- **费用实时预览**:预计佣金/印花税/过户费/合计扣款(买入)或净到账(卖出)
- 服务端校验,拒绝原因用人话表述,例如:
  - "现金不足:需 ¥10,007.50,可用 ¥9,500.00"
  - "委托价 11.00 超出今日跌停价 10.80,请调整价格"
  - "今天买入的 100 股明天才能卖(A股 T+1 规则)"
  - "买入数量必须是 100 股的整数倍"
  - "当前价 10.50 高于你的委托价 10.00,未成交(暂不支持挂单等待)"
- 成交后展示成交回执:成交价、数量、各项费用、剩余现金

### 3.4 持仓与资产页

- 持仓列表:股票、持仓量/可用量、成本价(含费用)、现价、市值、浮盈亏(额与百分比)
- 账户摘要:可用现金、持仓市值、总资产、总盈亏(相对初始 10 万)
- 资产曲线图(按日快照)
- 历史成交记录表;"重置账户"按钮(二次确认)

### 3.5 复盘与学习页

**复盘:**
- 每笔卖出成交后可填写"这笔交易的理由/反思"(可选,下单时也可备注)
- 平仓记录表:股票、持有天数、买入理由、卖出理由、盈亏额与百分比
- 统计卡:胜率、累计已实现盈亏、平均持有天数、平均每笔盈亏、交易笔数

**学习:**
- 新手引导(首次自动弹出):高亮遮罩分步导览,约 6 步走完 行情→个股→下单→持仓→复盘→学习,可跳过,进度存本地
- 课程区:短文课程(markdown),初版 6 篇:①股票是什么/A股市场 ②怎么看K线与分时 ③涨跌停与T+1 ④交易费用算一算 ⑤五档盘口与成交量 ⑥新手常犯的错
- 术语表:全部术语卡可浏览、可搜索

## 4. 交易规则(引擎需求)

### 4.1 板块与申报规则表

| 板块 | 代码特征 | 涨跌幅 | 申报单位 |
|---|---|---|---|
| 沪深主板 | 60xxxx / 00xxxx | ±10%(ST/*ST ±5%) | 100 股整数倍 |
| 创业板 | 30xxxx | ±20% | 100 股整数倍 |
| 科创板 | 688xxx | ±20% | ≥200 股,按 1 股递增 |
| 北交所 | 43/83/87/92 等 | — | 不提供交易,界面提示 |

涨跌停价格边界**优先采用行情接口返回的涨停价/跌停价**(腾讯接口自带,自动涵盖 ST 等特殊情形);接口未提供时按上表计算。委托价必须严格在 [跌停价, 涨停价] 区间内(含边界)。价格最小单位 0.01 元。

### 4.2 费用(配置项,精确到分)

| 项目 | 费率 | 方向 | 最低 |
|---|---|---|---|
| 佣金 | 0.025% | 买、卖 | ¥5.00/笔 |
| 印花税 | 0.05% | 仅卖出 | 无 |
| 过户费 | 0.001% | 买、卖 | 无 |

买入总成本 = 成交额 + 佣金 + 过户费;卖出净得 = 成交额 − 佣金 − 印花税 − 过户费。持仓成本价 = 累计买入总成本 ÷ 持股数(含费成本)。

### 4.3 T+1 与交易日历

- 每笔买入记录批次日期,可卖数量 = 所有"买入日期早于当前交易日"批次之和
- 交易日历从该股真实日K数据反推(有K线的日期即交易日),按年缓存;节假日无需手工维护
- 盘后模式的 T+1 边界:下一根真实K线的日期

### 4.4 撮合模型(v1 简化,界面如实标注)

- 即时成交:买入委托价 ≥ 最新价 → 按最新价成交;卖出委托价 ≤ 最新价 → 按最新价成交;否则拒绝并提示(不做挂单)
- 盘中最新价 = 实时报价;盘后(15:00 后、周末、节假日、9:30 前)= 最新收盘价,界面显示"盘后模式"角标
- 卖出按批次先进先出(FIFO)减扣,实现盈亏 = 卖出净得 − 对应批次含费成本

## 5. 技术架构

```
股票学习/
├── server/                  # Node.js ≥20 + Express
│   ├── src/market.js        # 行情服务:腾讯实时/五档(GBK解码)、东财K线/搜索;内存缓存+TTL;失败重试×2
│   ├── src/engine/          # 交易引擎(纯函数,无IO)
│   │   ├── fees.js          #   费用计算
│   │   ├── validate.js      #   规则校验(涨跌停/手数/T+1/资金)
│   │   ├── execute.js       #   撮合与持仓更新(FIFO)
│   │   └── calendar.js      #   交易日历(日K反推,按年缓存)
│   ├── src/store.js         # JSON文件存储(data/目录,临时文件+rename原子写,写前备份)
│   ├── src/content.js       # 术语表/课程markdown读取
│   └── src/index.js         # 路由、静态托管 web/dist、启动
├── web/                     # Vue 3 + Vite + Pinia
│   └── src/views/           # Market / StockDetail / Portfolio / Review / Learn
│   │   + components: KLineChart、OrderPanel、TermPopover、GuidedTour、FeePreview
│   └── vite.config.js       # dev 代理 /api → localhost:8090
├── content/
│   ├── terms.json           # 术语表
│   └── lessons/*.md         # 课程文章
├── data/                    # 账户数据(account.json 等,git 忽略,自动生成)
├── 启动.bat                 # 缺依赖则安装→缺构建则构建→起服务→开浏览器 localhost:8090
└── package.json             # 根工作区脚本:start / dev / build / test
```

- 端口:服务 8090;开发模式 Vite 5173 代理 /api
- 行情轮询:前端 5 秒(自选+持仓+当前个股合并批量请求),标签页隐藏时暂停(visibilitychange)
- 交易引擎为纯函数:`(订单, 最新行情, 账户状态, 日历) → 成交结果 | 拒绝原因`,服务层负责加锁串行下单与落盘

## 6. API 设计(REST,JSON)

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/market/indices | 三大指数报价 |
| GET | /api/market/quotes?symbols=sh600519,... | 批量实时报价(含五档、涨跌停价) |
| GET | /api/market/kline?symbol=&klt=day\|week\|minute&limit= | K线(东财,klt: 101日/102周/1分时;前复权) |
| GET | /api/market/search?q= | 搜代码/名称,仅A股,含板块标记 |
| GET | /api/meta/status | { mode: live\|afterHours, time } 盘中/盘后 |
| GET | /api/account | 现金、持仓(含批次)、初始资金 |
| POST | /api/orders | 下单 { symbol, side, price, qty, note? } → 成交明细(含费用拆解)/拒绝原因 |
| GET | /api/trades?limit= | 历史成交 |
| GET | /api/review/summary | 平仓明细+胜率/平均持有天数等统计 |
| POST | /api/account/reset | 重置为初始 10 万 |
| GET | /api/content/terms | 术语表 |
| GET | /api/content/lessons/:id | 课程markdown(渲染后前端展示) |

错误约定:HTTP 200 + `{ ok: false, reason: "人话原因" }` 用于业务拒绝;5xx 用于服务端故障。

## 8. 上游数据源

| 用途 | 来源 | 备注 |
|---|---|---|
| 实时报价+五档+涨跌停价 | 腾讯 qt.gtimg.cn/q=sh600519 | GBK 编码需 iconv-lite;批量一次最多 ~60 只 |
| 日/周/分时K线 | 东方财富 push2his kline 接口 | secid: 沪=1.xxx 深=0.xxx;klt 101/102/1;fqt=1 前复权 |
| 搜索 | 东方财富 searchapi suggest | 过滤仅保留沪深A股票 |

缓存:报价 3 秒 TTL 内复用;日K 当日缓存;日历按年缓存至内存。所有上游请求 5 秒超时,失败重试 2 次(退避 500ms/1s)。

## 9. 错误处理

- 上游失败(重试后仍失败):报价区显示横幅"行情获取失败,当前显示 HH:MM 数据",K线区显示重试按钮;不阻塞已入页面
- 盘后模式角标 + 下单面板顶部提示,避免用户误以为在实时盘中
- 本地存储:临时文件 + rename 原子写,写前保留 .bak;启动时若 JSON 损坏则从 .bak 恢复并提示
- 下单串行化(内存队列),避免并发双花

## 10. 测试策略

- **引擎单元测试(vitest,全量覆盖)**:
  - 费用:最低佣金触发线(成交额 ¥20,000 恰好 ¥5)、四舍五入到分、买入/卖出拆解
  - 涨跌停:边界价可成交/超出一分钱拒绝;ST ±5%(用接口返回边界);科创板 200/201 股合法、199 拒绝;主板 150 股拒绝
  - T+1:当日买入不可卖、跨周末/节假日(用真实日历)次日可卖;FIFO 多批次减扣与盈亏
  - 撮合:买入价高于现价成交、低于现价拒绝;盘后按收盘价
  - 资金不足拒绝;清仓后持仓删除、可用量正确
- **存储测试**:原子写、损坏恢复、重置
- **行情服务测试(mock fetch)**:GBK 解析、字段映射、缓存命中、重试逻辑
- **UI 手动清单**:首次引导完整走通 / 盘后下单显示角标 / 断网横幅 / 术语卡弹出 / 复盘统计与手动计算一致 / 重置后回到 10 万
