## 部署方案:Docker 镜像 + 服务器部署 + Basic Auth 访问保护

目标:打包成 Docker 镜像搬到你的服务器,公网可访问但仅自己使用(加口令保护),数据与 AI 密钥安全不入库。

### 一、应用内 Basic Auth(公网仅自己访问)

- 新增 `server/src/auth.js`:环境变量 `AUTH_USER` + `AUTH_PASS` 都配置时启用 HTTP Basic Auth(`crypto.timingSafeEqual` 防时序比较);**未配置则直接放行**,本地双击 启动.bat 行为完全不变
- 白名单 `/api/meta/status`(仅暴露盘中/盘后状态,无敏感数据),供容器健康检查使用
- `server/src/index.js` 在 `express.json()` 之后挂载中间件 → 保护全部 API + 静态资源 + AI SSE;浏览器弹原生登录框后,前端所有 fetch/SSE 同源自动带凭据,前端零改动
- 新增 `server/src/auth.test.js`(vitest):未配置放行 / 无凭据 401 / 错误凭据 401 / 正确凭据放行 / 白名单路径放行

### 二、清理构建障碍

- 删除 `server/package.json` 与 `web/package.json` 中代码从未引用的 `"stock-learning": "file:.."` 自引用依赖(已 grep 确认无引用),否则 Docker 内安装会拖入整个仓库
- 删除后跑全量测试确认无损

### 三、Docker 化

- **`Dockerfile`(多阶段)**:
  - 阶段1 `node:22-alpine`:装 web 依赖 → vite build 出 dist
  - 阶段2 `node:22-alpine`:装 server 生产依赖(express + iconv-lite,很小)、拷 dist;`apk add tzdata`
  - `ENV TZ=Asia/Shanghai`(关键!服务端用本地时间判盘后/交易日,不设时区交易时段判定全错)、`DATA_DIR=/data`、`NODE_ENV=production`
  - `VOLUME /data`、`EXPOSE 8090`、HEALTHCHECK(打 /api/meta/status)、非 root 用户运行
- **`.dockerignore`**:node_modules、data、.git、docs、design、web/dist、.env 等,镜像最小化
- **`docker-compose.yml`**(服务器一键部署):端口 8090 映射、`./data:/data` 数据卷持久化、环境变量从 `.env` 引用(`AUTH_USER`/`AUTH_PASS`/`ZHIPU_API_KEY`,AI 密钥走环境变量注入,llm.js 原生支持)、`restart: unless-stopped`
- **`.env.example`** 示例文件;`.gitignore` 加 `.env`(红线:密钥不入库)

### 四、部署文档

- **`docs/deploy.md`**:服务器前置(docker/compose 安装)、两条交付路线(A. 服务器 clone 私有仓库后 compose 构建,更新方便,推荐;B. 本地 `docker build` → `docker save` → scp → `docker load`,不用在服务器配 GitHub 凭据)、.env 配置说明、启动/更新/数据备份命令、国内服务器镜像加速备注(Docker Hub/npm 源)、防火墙安全组只放行 8090、可选附录:有域名时用 Caddy 套自动 HTTPS(Basic Auth 明文传输,公网建议)
- README 快速开始加 Docker 部署入口一行

### 交付物

你在服务器上只需:放好 `.env`(口令 + 智谱 key)→ `docker compose up -d` → 浏览器开 `http://服务器IP:8090` 输入口令即用。具体命令清单写在 docs/deploy.md。
